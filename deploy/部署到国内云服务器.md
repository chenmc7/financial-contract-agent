# ContractGuard 部署到国内云服务器 —— 完整操作手册

> 目标：让**每个组员在国内任何网络**都能随时打开，服务 7×24 在线不依赖本机。
> 方案：腾讯云/阿里云轻量服务器 + systemd 托管（开机自启、崩溃自动重启）+ DeepSeek 大模型（国内直连，无需梯子）。

---

## 第 1 步：购买服务器（约 10 分钟）

| 项 | 建议 |
|---|---|
| 厂商 | 腾讯云 或 阿里云（新用户轻量服务器常有几十元/首年优惠） |
| 配置 | 轻量应用服务器，**2核 2G** 起步即可（本项目很轻量） |
| 系统 | **Ubuntu 22.04 LTS**（64 位） |
| 地域 | 离你/组员近的：广州 / 上海 / 北京 |
| 带宽 | 轻量默认 4-6 Mbps，够用 |
| 付费 | 先按年付最便宜的套餐（新用户约 50~150 元/首年） |

> 提示：如果组员遍布全国，选广州或上海（国内互联互通较好）。买完记住**服务器 IP**、**root 密码或密钥**。

## 第 2 步：放行防火墙端口

- 在云厂商控制台 → 防火墙/安全组 → **放行 TCP 8900**（入方向，来源 0.0.0.0/0）。
- 说明：用 `http://IP:8900` 非标准端口访问，**不需要域名备案**。

## 第 3 步：准备 DeepSeek API Key（国内直连，无需梯子）

1. 打开 https://platform.deepseek.com → 注册 → 创建 API Key（格式 `sk-...`）。
2. 充值几块钱即可（按量计费，便宜，演示够用）。
3. 项目代码原生支持 DeepSeek（`engines/ai_client.py` 内置预设），切换时自动清除代理配置。

> 如果不想用 DeepSeek，也可以：智谱 `zhipu`（glm-4-flash 有免费档）、通义 `qwen`、Kimi `moonshot`，改 deploy.sh / service 里的 PROVIDER 即可。

## 第 4 步：把代码传到服务器（本机执行）

项目目录：`~/Desktop/商策大赛/contractguard`

```bash
# 用 scp（Windows 可用 WinSCP/宝塔面板，或 git 私有仓库 clone）
scp -r ~/Desktop/商策大赛/contractguard root@<服务器IP>:/opt/
```

## 第 5 步：一键部署（服务器上执行）

```bash
ssh root@<服务器IP>
bash /opt/contractguard/deploy/deploy.sh
```

脚本会：装依赖 → 建 venv → 装 Python 包 → 写入 API Key → 安装 systemd 服务 → 放行防火墙。
完成后输出公网地址：`http://<服务器IP>:8900`

## 第 6 步：导入本机数据（保留现有 11 条合同）

在**本机**把数据打包，上传到服务器覆盖（首次部署时执行）：

```bash
# 本机执行
cd ~/Desktop/商策大赛/contractguard
# 先停掉 8899 的本地服务，确保数据库是干净的
rsync -av data/contractguard.db uploads/ root@<服务器IP>:/opt/contractguard/data/
# 修正上传文件属主
ssh root@<服务器IP> "chown -R root:root /opt/contractguard && systemctl restart contractguard"
```

> 注意：上传前请确认本机 8899 服务已停止（避免 WAL 不一致）。之后**本机与服务器数据不再自动同步**（服务器是唯一正式库）——如需再次同步，重复第 6 步即可。

## 日常运维

```bash
# 查看状态
systemctl status contractguard
# 实时日志
journalctl -u contractguard -f
# 重启服务
systemctl restart contractguard
# 开机自启已由 systemd 保证，服务器重启后服务自动恢复
```

## 常见问题

- **组员打不开？** 检查：① 云控制台安全组是否放行 8900；② `ufw status` 是否放行；③ 服务器上 `curl http://127.0.0.1:8900/api/health` 是否 200。
- **AI 问答提示无法连接？** 检查 `.env` 里 `CONTRACTGUARD_API_KEY` 是否正确、余额是否充足；`journalctl -u contractguard` 查看报错。
- **想用 80 端口/域名？** 国内服务器用 80/443 需要域名备案，比赛演示阶段没必要，直接用 IP:8900。
- **安全提醒**：该地址任何人拿到都能访问。比赛结束后建议在安全组关闭 8900 或直接销毁服务器。
